# h9pic-bootloader
PIC18F46K80 bootloader for a h9 project.

## Node identity
The bootloader reports the node identity in the `BOOTLOADER_TURNED_ON` frame.
These values are compiled into the bootloader and must be passed at configure time with `-D`:

| Variable       | Description                         | Example  |
|----------------|-------------------------------------|----------|
| `NODE_TYPE`    | Node type (16-bit, broadcast group) | `0x0102` |
| `PCB_REVISION` | PCB revision (letter `A`-`Z`)       | `B`      |
| `BOM_REVISION` | BOM revision (1 byte)               | `1`      |

Configuration fails if any of them is missing.

## Example
Using the CMake project generated by MPLAB (`cmake/h9pic-bootloader/default`):
```
cmake --preset h9pic_bootloader_default_conf -S cmake/h9pic-bootloader/default \
      -D NODE_TYPE=0x0102 -D PCB_REVISION=B -D BOM_REVISION=1
cmake --build _build/h9pic-bootloader/default
```

The values are stored in the CMake cache, so they only need to be given once per build directory.
To change them, run `cmake` again with new `-D` values.
